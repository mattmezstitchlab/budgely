PROTOTYPELe Studio fonctionne (vos campagnes sont enregistrées sur cet appareil et le lien de piste est réel), mais l’inventaire et les estimations sont des données de démonstration. Pendant le pilote, les placements sont gratuits et choisis avec vous.

Nouvelle campagne

Il est analysé dans le navigateur du joueur : tempo, premier temps, tonalité. Le niveau se construit dessus.
En créant une campagne vous confirmez détenir les droits du contenu, et vous acceptez qu’il soit identifié comme partenaire. Pas de ciblage des moins de 15 ans, pas de publicité comportementale, pas de contenu sans bande-son.
VOS CAMPAGNES

Ce que vous achetez exactement

  • Une piste jouée = un niveau de CHROMA terminé sur votre contenu : ≈ 3 minutes, mains sur le morceau. Un niveau abandonné avant 50 % n’est pas facturé.
  • Le taux « dans le tempo » : part des gestes du joueur calés sur votre beat. C’est une preuve d’attention impossible à simuler par un bot ou un onglet en arrière-plan.
  • Les partages portent le code du joueur ; les conversions sont attribuées à ce code. Le joueur prescripteur touche une commission sur la vente — jamais sur le clic.
  • Rien n’est généré ailleurs : aucun stream, aucune vue, aucun clic n’est envoyé vers Spotify, YouTube ou une régie. Votre contenu est écouté ici, et vos fans convertissent chez vous.
